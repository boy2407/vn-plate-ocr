# Kaggle OCR image review samples

Twelve image crops selected from the `cropped/` folder of [Vietnamese License Plate OCR](https://www.kaggle.com/datasets/topkek69/vietnamese-license-plate-ocr), dataset owner Namu Desu (`topkek69`), version 9. Dataset license: Apache 2.0. These are review examples only; they are not added to any training split.

`manifest.csv` records the transcription and screening statistics. Mean luminance and standard deviation are normalized to 0–1 and were used only to shortlist examples for visual inspection; they do not constitute ground-truth lighting labels.
