# HSV hue-shift previews

Four source crops with white, yellow, blue, and red/magenta plate backgrounds are shown unmodified and with H shifts. Only H changes; S and V stay fixed. Offsets use the OpenCV 8-bit hue scale (0–179): ±8 means about ±16 degrees. White/gray low-saturation regions naturally change little.

These are exaggerated visual examples to make color effects easy to inspect, not proposed final training values. Large hue shifts can turn a real plate background into an implausible color.
